# 👕 3D Dress Customizer

A modern **3D T-Shirt customization web application** where users can design their own shirts in real time.  
Users can change colors, upload images, and generate AI-based designs directly onto a 3D shirt model.

---

## 🚀 Features

- 🎨 Dynamically change shirt colors
- 🖼 Upload custom images
- 🤖 Generate AI images from text prompts
- 👕 Apply logo or full textures to the 3D shirt
- 🌐 Real-time 3D preview
- ✨ Smooth animations and transitions

---

## 🧠 AI Image Generation

Originally integrated with **OpenAI**, but due to **API credit limitations**, the project now uses the **Hugging Face Inference API** for generating images.

- Enter a prompt describing the design
- Generate an AI image
- Apply the generated image directly to the 3D shirt model
